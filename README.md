# Andyford Osei Boateng — Portfolio

A responsive personal portfolio built with plain HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract this folder.
2. Open `index.html` in a web browser.
3. Edit the HTML/CSS to update content or styling.

## Before publishing
- Verify all contact links and descriptions.
- Never add `.env`, passwords, API keys, database files or private student information.
- The Student Clearance Portal is marked as in development/testing. It has no public live demo; deployment is pending school/supervisor approval.
- Only add screenshots after replacing real names, student numbers and other private information with dummy data.

## Technology
HTML5, CSS3 and vanilla JavaScript. No package installation is required.
